# Host Value Check

Hiring-exercise prototype for an Opiniion Senior Product Manager interview.

The case is a hypothetical Airbnb host-retention problem. The page uses Airbnb-like visual language so a host flow feels concrete. It is not an Airbnb product, and it does not use Airbnb trademarks or live data.

Market bands, occupancy response, and hour benchmarks are simulated. Scope and math are defined in the prototype PRD in the job-search workspace: `Job Descriptions/Opiniion - Host Retention - Prototype PRD.md`.

## Run locally

Open `index.html` in a browser, or:

```
npx serve .
```

## Publish

GitHub Pages from the `main` branch, root folder.
